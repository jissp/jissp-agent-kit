# databases

스킬이 **프로젝트와 무관하게 전역으로 유지해야 하는 데이터**를 두는 디렉토리입니다.
프롬프트·규칙 문서(`skills/`, `*.md`)와 달리, 여기에는 스킬이 런타임에 생성·갱신하는 **데이터**만 들어갑니다.

## 규약

- 데이터 저장소 하나당 디렉토리 하나를 씁니다. 디렉토리명은 복수형 kebab-case를 사용합니다. (예: `todos`)
- 각 저장소의 **구조·스키마 정의는 데이터가 아니라 스킬 문서**에 둡니다. 여기에는 데이터만 남깁니다.
- 프로젝트에 종속되는 데이터(태스크·설계 문서 등)는 여기가 아니라 각 프로젝트의 `0-jissp-docs/` 에 둡니다.

|---|---|---|---|
