# [메시지 양식] 슬랙 스레드 공유 메시지

STEP 5에서 `jissp-slack-message-sender`에 넘길 **메시지 양식**입니다. 문서 유형에 맞는 양식 하나를 골라 넘깁니다.
이 파일은 **무엇을 담을지(항목)** 만 정합니다. 문체·분량·슬랙 문법·비개발자용 표현 규칙은 sender의 `templates/writing-rules.md`가 맡습니다.

- 각 항목은 STEP 4에서 저장한 분석 문서에서 채웁니다.
- `{ }` 안의 선택지 중 분석 문서의 판정에 맞는 것 하나를 씁니다.
- 해당 없는 항목은 생략합니다.

## 버그/이슈 제보

```
**[문의 확인 결과] {한 줄 제목}**

**결론**: {문제가 맞습니다 / 정상 동작입니다 / 특정 조건에서만 발생합니다 / 추가 확인이 필요합니다}
**어떤 현상인가요**: {사용자 화면·행동 기준 현상}
**왜 그런가요**: {원인}
**영향 범위**: {누가 / 언제부터 / 얼마나 — 확인된 범위만}
**앞으로 어떻게 하나요**: {개선 방향 + 예상 일정 또는 일정 논의 필요 여부}
**확인 부탁드려요**: {답이 필요한 질문 — 있을 때만}
```

## 업무 요청

```
**[요청 검토 결과] {한 줄 제목}**

**결론**: {가능합니다 / 조건부로 가능합니다 / 현재 구조로는 어렵습니다 / 추가 확인이 필요합니다}
**요청 내용**: {요청을 한 문장으로 다시 정리}
**지금은 어떻게 동작하나요**: {현행 동작}
**영향 범위**: {바뀌면 함께 영향받는 화면·기능·사용자}
**다음 단계**: {진행에 필요한 일 + 예상 일정 또는 일정 논의 필요 여부}
**확인 부탁드려요**: {결정이 필요한 사항 — 있을 때만}
```
