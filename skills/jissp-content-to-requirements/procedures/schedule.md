# [처리 절차] 일정 관리 — 일정 정리

일정 관리(일정 조율·마감 기한·마일스톤 등)로 분류된 건은 아래 절차를 순서대로 진행합니다.

## 1. 일정·액션 아이템 추출
- **확정된 일정**과 **조율 중인 일정**을 구분합니다.
- 각 일정의 일시/기한·담당자·조건을 원문 근거로 기재합니다.
- 액션 아이템은 담당자·기한과 함께 목록화합니다.
- 상대 날짜("다음 주 수요일" 등)는 원문 작성 시점 기준의 **절대 날짜로 변환**합니다. 기준을 알 수 없으면 '확인 필요 사항'으로 남깁니다.

## 2. 본문 가공
이 스킬 디렉토리의 `templates/schedule-summary.md` 양식으로 가공합니다. (SKILL.md의 [반환 규칙] 참고)
- **파일로 저장하지 않습니다.** 저장은 호출자의 몫입니다.

## 3. 요약 작성
- 본문과 함께 반환할 요약에는 확정 일정 / 액션 아이템 / 미확정 항목만 간결히 담습니다.

## 4. 절차 종료 후
[반환 규칙]의 4개 항목(문서 유형·핵심 키워드·문서 본문·요약)을 갖춘 뒤 SKILL.md [종료 처리]에 따라 분기합니다.
- 다른 스킬이 호출한 경우: 여기서 응답을 끝내지 말고 **호출한 스킬의 다음 단계로 복귀**합니다.
- 사용자가 직접 호출한 경우: 본문 전문과 요약을 채팅에 출력하고 종료합니다.
