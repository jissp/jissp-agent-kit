# [처리 절차] 잡담·기타 — 요약 방향 질문

잡담이거나 다른 유형 어디에도 해당하지 않는 건은 아래 절차를 순서대로 진행합니다.

## 1. 요약 방향 질문 [필수]
**임의로 요약하지 말고** `AskUserQuestion` 도구로 사용자에게 어떻게 요약하면 되는지 질문합니다.
- 질문에는 원문에서 파악한 주제 한 줄 요약을 포함합니다.
- 선택지 예: **핵심 논점 요약** / **아이디어 정리** / **결정사항·액션 아이템만 추출** / **문서화 불필요(종료)** — 원문 성격에 맞게 구성하고, 그 외 방향은 Other로 받습니다.
- 사용자가 **문서화 불필요**를 선택하면 사유만 남기고 종료합니다.

## 2. 본문 가공
- 합의된 방향에 따라 노이즈를 제거한 명확한 본문을 작성합니다. (별도 템플릿이 없으므로 사용자와 합의한 형식을 따릅니다)
- **파일로 저장하지 않습니다.** 저장은 호출자의 몫입니다. (SKILL.md의 [반환 규칙] 참고)

## 3. 요약 작성
- 본문과 함께 반환할 요약에는 합의된 방향 기준의 핵심만 간결히 담습니다.

## 4. 절차 종료 후
[반환 규칙]의 4개 항목(문서 유형·핵심 키워드·문서 본문·요약)을 갖춘 뒤 SKILL.md [종료 처리]에 따라 분기합니다.
- 다른 스킬이 호출한 경우: 여기서 응답을 끝내지 말고 **호출한 스킬의 다음 단계로 복귀**합니다.
- 사용자가 직접 호출한 경우: 본문 전문과 요약을 채팅에 출력하고 종료합니다.

단, 1단계에서 **문서화 불필요**로 종료한 경우에는 가공할 본문이 없으므로 그대로 종료합니다. 다른 스킬이 호출했다면 `문서화 불필요`로 종료했다는 사실만 넘기고, 이후 진행 여부는 호출한 스킬이 판단합니다.
