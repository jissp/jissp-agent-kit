# jissp-planner 기본 설정

본 스킬이 문서 경로·파일명·Rule 문서·리뷰 설정 문서를 해석하는 **기본값**입니다. 프로젝트 설정 파일이 있으면 그 파일의 값이 이 기본값을 덮어씁니다.

- 이 파일은 `init` 모드가 프로젝트 설정 파일을 만들 때 쓰는 **양식**이기도 합니다. `init` 은 아래 `## 프로젝트 설정 항목` 이하를 그대로 복사해 프로젝트 설정 파일을 만듭니다.
- 스킬을 다른 환경에 배포할 때 문서 루트 디렉토리명을 바꾸려면 `## 스킬 고정 항목` 의 값을 수정합니다.

## 스킬 고정 항목

프로젝트 설정 파일로 덮어쓸 수 없는 항목입니다. (설정 파일을 찾는 기준 경로이므로, 설정 파일 안에서 바꾸면 설정 파일을 찾을 수 없게 됩니다.)

- **문서 루트명**: `0-jissp-docs`
  - `[Jissp 문서]` = `[프로젝트 루트]/0-jissp-docs`
  - `[프로젝트 루트]` = 스킬을 호출한 현재 작업 디렉토리
- **프로젝트 설정 파일**: `[Jissp 문서]/rules/jissp-planner/config.md`

## 프로젝트 설정 항목

### 세부 디렉토리

`[Jissp 문서]` 하위 경로입니다.

- **공통 Rule 관리 문서**: `rules`
- **PRD 문서**: `prds`
- **설계 문서**: `plans` (구조 문서 `*-structure.md` 도 여기에 저장)

### 파일명 규칙

- **형식**: `[YYYYMMDD_HHmmss]_[feature]-[문서 유형].md`
  - `[YYYYMMDD_HHmmss]`: 반드시 `date +%Y%m%d_%H%M%S` 명령(Bash)으로 현재 시각을 얻어 사용합니다. 추정하거나 시분초를 생략하지 않습니다.
  - `[feature]`: 기능/주제를 나타내는 kebab-case 식별자
  - `[문서 유형]`: PRD 문서 `prd`, 구조 문서 `structure`, 설계 문서 `architecture`
- **예시**: `20260923_143205_export-csv-prd.md`, `20260923_150312_export-csv-architecture.md`

### 설계 Rule 문서

structure·architecture 모드가 따르는 프로젝트 설계 규칙 문서입니다. `init` 모드가 프로젝트를 분석해 생성합니다.

- **경로**: `[공통 Rule 관리 문서]/planner-architecture/README.md`

### 추가 Rule 문서

설계 Rule 문서 외에 함께 따라야 하는 프로젝트 문서입니다. (예: 코딩 컨벤션, 도메인 용어집) 경로는 `[프로젝트 루트]` 기준 상대 경로로 적습니다.

- (없음)

### 모듈 문서

모듈의 현재 동작·불변식을 정리한 문서(예: 모듈별 `README.md`)의 경로 패턴입니다. structure·architecture 모드가 코드 분석 단계에서 **작업 범위에 든 모듈의 문서만** 탐색 출발점으로 읽습니다. 신뢰할 수 있는 문서만 걸리도록 패턴을 좁게 적으세요. `[프로젝트 루트]` 기준 glob 패턴으로 적습니다.

- (없음)

### 설계 문서 예시

architecture 모드가 문서 양식의 참고 예시로 읽는 실제 설계 문서입니다. 같은 프로젝트에서 잘 작성된 설계 문서 하나를 지정하면 문서 품질이 올라갑니다. `[프로젝트 루트]` 기준 상대 경로로 적습니다.

- (없음)

### 리뷰 설정 문서

review 모드가 적용하는 프로젝트별 리뷰 설정(추가 검토 관점·제외 항목·심각도 조정·추가 기준 문서·실행 옵션)입니다. `init` 모드가 `modes/review/review-config.default.md` 양식으로 생성합니다. 파일이 없으면 스킬 기본 동작으로 검토합니다.

- **경로**: `[공통 Rule 관리 문서]/jissp-planner/review-config.md`
