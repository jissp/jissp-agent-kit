## 5. 실행 옵션

- **코드 대조**: `auto`
  - `auto`: 검토 대상 문서에 경로가 있으면 코드 대조 레인을 수행 (기본)
  - `off`: 코드 대조 레인을 띄우지 않음 (문서 내부 검토만 수행)
- **자체 수정 가능 항목 처리**: `auto`
  - `auto`: 발견 사항 보고 후 즉시 수정 (기본)
  - `confirm`: 사용자 결정 필요 항목과 함께 수정 여부를 확인받은 뒤 수정
- **재검증**: `auto`
  - `auto`: 수정 범위가 넓거나 구조적 변경이 있을 때만 1회 (기본)
  - `always`: 문서를 수정했으면 항상 1회
  - `off`: 재검증하지 않음
