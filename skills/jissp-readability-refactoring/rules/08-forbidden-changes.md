# 2. 금지되는 변경 카테고리

다음은 가독성 개선처럼 보여도 본 SKILL의 책임이 **아니다**. 발견하더라도 손대지 말고 "범위 외 관찰"로만 보고한다.

- 알고리즘/로직 변경 (O(n²) → O(n) 등)
- 자료구조 변경 (Array → Map, Set 도입 등)
- 추상화/패턴 도입 (Strategy, Factory, Generic 등)
- 라이브러리/API 교체 (`forEach` → `map`, callback → Promise 등)
- 성능 최적화 (메모이제이션, 캐싱, 조기 종료 추가 등)
- 타입 시스템 강화 (any → 정확한 타입 — 명백한 오류라도 보고만)
- 포맷/스타일 변경 (들여쓰기, 따옴표, 세미콜론 — 포매터의 영역)
- 무의미한 주석 대량 추가
