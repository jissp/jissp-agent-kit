# 1-4. 매직값 의미화

> 카테고리: **허용되는 변경** (읽는 사람의 인지 부하를 줄이는 변경만 수행한다)

- 매직 넘버/스트링을 명명된 상수로 (예: `['2001', '2211']` → `const successCodes = [...]`)
- 매직 계산을 의도가 드러나는 유틸로 (`Math.round((amount * 10) / 11)` → `VatUtil.getSupplyAmount(amount)`) — **이미 존재하는 유틸로 교체할 때만.** 새 유틸을 만드는 것은 `rules/09`의 추출 조건을 따르며, 새 파일이 필요하면 적용하지 않는다
- 단, 한 곳에서만 쓰이고 문맥상 명확하면 추출하지 않는다
